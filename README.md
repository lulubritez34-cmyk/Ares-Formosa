# Ares: Loro Digital de Mitos y Leyendas Formoseñas

Este proyecto es un agente conversacional interactivo en 3D que representa a **Ares**, un loro hablador (*Amazona aestiva*) experto en la cultura, geografía, mitos y leyendas de la provincia de Formosa, Argentina.

## Tecnologías Utilizadas
- **Three.js (0.160):** Renderizado 3D de cuerpo completo, iluminación y controles orbitales de 360°.
- **ElevenLabs SDK (`@elevenlabs/client`):** Motor conversacional de voz con sincronía labial basada en caracteres y fonemas.
- **Web Audio API:** Analizador de frecuencias de voz para complementar el movimiento del pico.

## Cómo probarlo localmente
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en un navegador web actual (Chrome, Edge, Firefox, Safari).
3. Permite el uso del micrófono o utiliza el modo de demostración sin conexión.
